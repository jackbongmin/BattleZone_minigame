# 🎮 Battle Arena - 2D Top-Down Multiplayer Action Game

Node.js(Express + Socket.io)와 HTML5 Canvas를 기반으로 구현된 최대 10인 동시 접속 탑다운 2D 실시간 웹 액션 게임입니다.

---

## 🌟 주요 특징 및 구현 내용

### 1. 진입 화면 (Lobby / Login)
- **닉네임 및 색상 선택**: 닉네임 입력 및 8가지 네온 컬러 팔레트 + 커스텀 컬러 피커 지원.
- **10인 정원 제한**: 최대 동시 접속 10명 제한. 10명 도달 시 입장 불가 안내 메시지 및 버튼 비활성화.
- **실시간 서버 접속 현황**: 현재 로비 및 게임 참가 인원을 실시간으로 표시 (`N / 10명`).

### 2. 캐릭터 조작 및 스펙
- **이동**: `W`, `A`, `S`, `D` 또는 방향키 (대각선 이동 시 속도 정규화 적용).
- **달리기**: `Shift` 키 유지 시 이동 속도 1.5배 (스태미나 초당 25 소모, 달리지 않을 시 초당 20 자동 회복).
- **체력 (HP)**: 100 HP. 머리 위 닉네임, 체력 바(HP 퍼센트에 따른 색상 전환), 스태미나 바 표시.
- **공격**: 마우스 좌클릭 또는 `Space` 키.
  - 전방 110도 부채꼴 영역 타격 판정 및 휘두르는 칼날(Slash) 시각 효과.
  - 쿨타임: 0.5초 (UI 쿨다운 인디케이터 제공).
- **사망 및 리스폰**:
  - HP가 0이 되면 회색 묘비(Tombstone) 상태로 전환 (`R.I.P` 석판 렌더링).
  - 10초 카운트다운 타이머 동작 후 맵 내 안전한 랜덤 좌표에 풀피(100 HP, 100 Stamina)로 부활.

### 3. 전투 및 상호작용 (Server-Authoritative)
- **PvP 데미지**: 플레이어 간 공격 적중 시 피격자에게 20 데미지 적용.
- **몬스터 시스템**:
  1. **근접형 몬스터 (Forest Goblin)**: 느린 속도로 배회하다 유저 인식 범위(320px) 내 접근 시 가장 가까운 유저에게 돌진. 접촉 시 유저에게 10 데미지. 처치 시 **10점** 획득.
  2. **원거리형 몬스터 (Cursed Mage)**: 배회 또는 거리 유지(카이팅). 유저 인식 시 유저 방향으로 마법 투사체(Projectile) 발사. 투사체 피격 시 유저에게 15 데미지. 처치 시 **20점** 획득.
- **스코어 & 킬로그**:
  - 다른 플레이어 처치 시 **50점** 획득.
  - 화면 우측 상단 실시간 스코어보드 (1위 플레이어 황금 왕관 👑 표시).
  - 실시간 처치 알림 킬로그 피드 (화면 좌하단).

### 4. 맵 & 그래픽 (Canvas 2D)
- 2200 x 2200 px 크기의 광활한 평원 맵.
- 맵 외곽 벽 충돌 및 고대 유적 기둥, 암석 등 장애물 충돌 판정 구현.
- 플레이어 중심 스무스 추적 카메라 (Lerp), 우측 하단 레이더 미니맵.
- Web Audio API 기반 절차적 사운드 효과 (스윙, 타격, 피격, 발사, 킬 팡파르).

### 5. 아키텍처
- 서버 틱 30Hz 단위로 모든 이동, 피격, 체력, 투사체, AI를 중앙 통제하는 **Server-Authoritative** 구조.
- 클라이언트는 입력 전송 및 서버 상태 스냅샷 수신/보간 렌더링 수행.

## 📁 프로젝트 구조

```
mini/
├── package.json               # 프로젝트 설정 및 의존성 (express, socket.io)
├── server/
│   ├── server.js              # Express 정적 서빙 및 Socket.io 이벤트 핸들러
│   ├── config.js              # 게임 밸런스, 틱레이트, 맵 크기, 상수 설정
│   └── game/
│       ├── GameManager.js     # 30Hz 서버 루프, 엔티티 관리, 피격/킬 판정
│       ├── Player.js          # 플레이어 이동, 스태미나, 공격 쿨타임, 리스폰
│       ├── Monster.js         # 근접/원거리 몬스터 AI 및 스폰
│       ├── Projectile.js      # 원거리 투사체 이동 및 충돌
│       └── Map.js             # 맵 크기, 장애물 배치, 충돌 판정
├── public/
│   ├── index.html             # 메인 HTML (로비 모달, Canvas, HUD)
│   ├── css/
│   │   └── style.css          # 모던 글래스모피즘 게임 UI 스타일
│   └── js/
│       ├── main.js            # 클라이언트 메인 루프, 소켓 통신, HUD 갱신
│       ├── renderer.js        # HTML5 Canvas 2D 렌더러 & 미니맵
│       ├── input.js           # 키보드(WASD/Shift/Space) 및 마우스 조준 입력
│       ├── camera.js          # 스무스 추종 카메라 시스템
│       ├── particles.js       # 데미지 플로팅 텍스트, 타격 불꽃 파티클
│       └── sound.js           # Web Audio API 사운드 시스템
└── README.md
```

## 🚀 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
```

### 3. 브라우저 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **`http://localhost:3000`**

(여러 브라우저 탭 또는 시크릿 모드 창을 열어 최대 10명까지 동시 멀티플레이를 테스트할 수 있습니다!)
